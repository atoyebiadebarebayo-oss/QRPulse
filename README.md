# ⚡ QR Pulse — Dynamic QR Code Generator Studio

A sleek, lightweight, and customizable QR code generator micro-SaaS designed for creators, digital storefronts, and business owners.

![QR Pulse Preview] https://qrpulse-chi.vercel.app

## ✨ Features
* 🎨 **Custom Styling**: Change foreground and background colors to match your brand palette.
* 📏 **Flexible Sizing**: Choose between Small (180px), Medium (240px), and Large (320px) output.
* 💾 **Instant PNG Download**: Download high-resolution QR images directly to your device.
* ⚡ **Zero Dependencies / Frameworks**: Built with pure HTML5, CSS3, and Vanilla JavaScript.
* 📱 **Fully Responsive**: Works seamlessly on mobile phones, tablets, and desktop displays.

## 🛠 Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Library**: QRCode.js (via CDN)
* **Hosting**: Vercel / Netlify / GitHub Pages
